# 말랑꼬치

모바일 터치로 떨어지는 캐릭터 떡을 받아 꼬치를 완성하는 프로모션 게임 프로토타입입니다.

## 실행

`index.html`을 브라우저로 열면 실행됩니다. 이미지, 스타일, 스크립트가 모두 포함되어 있어 별도 설치나 외부 서비스가 필요 없습니다.

모바일에서는 정적 웹 서버에 올린 주소로 접속하세요. 로컬 미리보기는 프로젝트 폴더에서 `python3 -m http.server 8765` 실행 후 `http://localhost:8765`로 접속할 수 있습니다.

## 게임 방식

- 터치 또는 마우스로 좌우 드래그해 꼬치를 이동합니다.
- 5개씩 두 스테이지, 총 10개의 떡이 무작위 위치에서 수직으로 떨어집니다.
- 중심 정렬에 따라 PERFECT / GREAT / GOOD / OK 점수를 받습니다.
- 연속으로 받으면 콤보 보너스가 붙고 놓치면 콤보가 초기화됩니다.
- 받은 떡의 좌우 위치는 그대로 유지되며 결과에서 두 꼬치를 보여줍니다.
- 일시정지와 재시작을 지원합니다. 다른 창으로 이동하면 자동으로 일시정지됩니다.
- PERFECT 진동은 브라우저와 기기 지원 여부에 따라 작동합니다.

## 구성

- `index.html`: 원본 캐릭터 이미지가 내장된 단일 HTML 게임
- 외부 라이브러리, 서버 저장, 계정 기능 없음

## 확인 상태

모바일 크기의 Chromium에서 드래그, 점수 판정, 쌓임 위치, 두 스테이지 결과, 재시작 및 작은 화면의 버튼 표시를 확인했습니다. 이후 크기와 속도를 조정하고 JavaScript 문법을 확인했습니다. 실제 휴대폰의 터치 체감과 진동은 추가 확인이 필요합니다.
